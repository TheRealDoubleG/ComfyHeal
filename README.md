# ComfyHeal

**Version 0.1 – Beta**

Healing and secure click-casting toolkit for **World of Warcraft: Forever**.

## 0.1 Beta

- Secure spell bindings for ComfyFrames unit buttons.
- Left, right, middle, mouse button 4/5 plus Shift/Ctrl/Alt left/right combinations.
- Secure attributes are only changed outside combat; edits made during combat are queued.
- Separate scope toggles for player, single-unit, party and raid frames.
- Dispel-type highlighting for Magic, Curse, Disease and Poison.
- Optional Dispel Center showing affected group/raid members.
- Dispel display types are user-selected filters; ComfyHeal does not pretend to know every spec/talent-specific dispel capability.
- Test mode for dispel visuals.
- Character, account and custom profiles.
- Designed to work with ComfyFrames without making gameplay decisions automatically.

## Important

The first beta intentionally targets ComfyFrames for secure click casting. Blizzard-frame click-casting integration, spellbook drag & drop, mouse-wheel secure bindings, HoT tracking and deeper heal prediction controls are planned for later betas after Forever ingame testing.

## Commands

- `/comfyheal`
- `/cheal`
- `/cheal test`

## Target

WoW Forever 1.60.1 / Interface 16001.

ComfyHeal provides UI and secure click bindings only. It does not automatically choose targets or cast spells.
